# geeslab-site

Gee's Lab official hub site.

## GitHub Pages

1. このリポジトリにファイルをアップロード
2. GitHub の `Settings` → `Pages`
3. `Build and deployment` の Source を `Deploy from a branch`
4. Branch を `main`、Folder を `/ (root)` に設定
5. Save

各リンク先は `index.html` 内の `href="#"` を実際のURLに置き換えてください。

独自ドメインを設定する場合は、GitHub Pages 側で Custom domain を設定してください。
